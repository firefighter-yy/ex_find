# TISSUE-006：导出格式保真原型与 ADR-0002

- 状态：完成
- 类型：技术验证
- 优先级：P0
- 依赖：TISSUE-002
- 关联：[PRD](../../PRD.md)、[ADR-0001](../adr/0001-local-desktop-search-and-excel-automation.md)

## 目标

通过真实或具有代表性的 Excel 样本比较两种导出策略，明确“全部保留”的可实现边界，并产出 ADR-0002 决定 MVP 默认导出模式。

## 候选策略

### 抽取模式

新工作簿仅包含命中的物理行。优先保证结果紧凑，但可能破坏跨行结构和工作簿对象引用。

### 原貌模式

复制完整来源工作表，通过隐藏、筛选或其他非破坏方式只展示命中行。优先保证原貌，但结果文件可能仍包含未命中数据。

## 样本矩阵

至少覆盖：

- 普通字体、填充、边框、对齐和数字格式。
- 行高、列宽、隐藏行列、冻结窗格和筛选。
- 横向及纵向合并单元格。
- 条件格式、数据验证和批注。
- 公式、跨行引用、跨表引用和外部链接。
- 图片、图表、形状和数据透视表。
- `.xlsm` 宏保留但不执行。
- 同一工作表内多个独立表格。
- 多个源文件存在同名工作表。

## 评估维度

- 命中结果是否准确。
- 源文件是否保持不变。
- 单元格及工作表级格式保真度。
- 公式和工作簿对象的语义完整性。
- 是否会把未命中敏感数据带入结果文件。
- 导出速度、文件体积和实现复杂度。
- 用户能否从结果追溯到源位置。

## 非范围

- 本任务只制作最小技术原型，不接入正式 UI。
- 不在 ADR 接受前实现生产级导出流程。
- 不承诺修复 Excel 自身不支持的跨工作簿复制行为。

## 验收标准

1. 两种候选策略均完成可重复运行的原型。
2. 样本矩阵每一项都有导出结果和明确结论。
3. 明确列出可完整保留、降级保留和无法保证的对象类型。
4. 明确说明原貌模式是否包含未命中数据及其隐私影响。
5. 形成并接受 ADR-0002，确定默认策略、可选策略及降级规则。
6. 原型未修改源文件，失败后未残留应用创建的 Excel 进程。

## 交付物

- 两种导出策略原型。
- 样本工作簿和验证记录。
- 性能与文件大小对比。
- `docs/adr/0002-*.md`。


## 实现

- 原型入口：src/ex_transform/export_fidelity.py。
- 单元测试：`tests/test_export_fidelity.py`。
- 真实 Excel 验证可通过设置 EXCEL_COM_INTEGRATION=1 后调用 ExportFidelitySpike.export 分别运行两种模式，并核对源文件哈希、大小和修改时间。
