# TISSUE-007：新工作簿导出

- 状态：待办
- 类型：功能
- 优先级：P0
- 依赖：TISSUE-005、TISSUE-006、已接受的 ADR-0002
- 关联：[PRD](../../PRD.md)、[ADR-0001](../adr/0001-local-desktop-search-and-excel-automation.md)

## 目标

将当前预览中的匹配结果通过 Excel COM 导出到用户选择的新 Excel 文件，并遵守 ADR-0002 确定的格式保真策略。

## 范围

- 从当前搜索结果创建不可变的导出快照。
- 打开 Windows 保存文件对话框，允许用户选择路径和文件名。
- 导出前验证源文件没有在准备后发生变化。
- 通过独立 Excel COM 实例执行复制和保存。
- 按 ADR-0002 处理工作表结构、格式、公式和对象。
- 处理多个源文件、同名工作表和 Excel 工作表名称限制。
- 保持结果顺序，并提供来源文件、来源工作表和原始行号的追溯方式。
- 报告进度、允许取消，并在完成后显示保存路径和结果数。

## 保存规则

- 不允许调用源工作簿的 `Save` 或 `SaveAs`。
- 只向用户选择的新路径写入。
- 覆盖已有文件必须由系统保存对话框明确确认。
- 导出应先写入同目录的临时文件，成功关闭并验证后再完成最终落盘。
- 失败或取消后不得留下看似完整的最终结果文件。

## 非范围

- 不修改或标记源文件。
- 不自动发送、上传或打开导出文件。
- 不在本任务中重新讨论 ADR-0002 已确定的默认策略。

## 验收标准

1. 导出行集合与用户点击导出时的预览结果一致。
2. 用户可选择保存目录和文件名。
3. 导出过程中源文件内容、大小和修改时间不变。
4. 多文件、同名工作表和多独立表格场景能成功导出并追溯来源。
5. 格式和对象保留符合 ADR-0002 的支持矩阵。
6. 源文件变化时阻止过期结果静默导出，并提示重新准备。
7. 取消或失败不会留下伪成功文件或应用创建的 Excel 进程。
8. 完成提示包含保存路径、结果行数和必要的降级警告。

## 测试要求

- 单文件、多文件、同名工作表和零结果场景。
- 路径无权限、目标文件占用、磁盘空间不足和用户取消。
- 导出期间源文件变化。
- ADR-0002 格式支持矩阵的回归测试。
- 导出前后源文件哈希或等价不变性检查。

## 交付物

- 导出应用服务和 Excel COM 实现。
- 保存对话框及进度交互。
- 格式回归测试和失败恢复测试。
