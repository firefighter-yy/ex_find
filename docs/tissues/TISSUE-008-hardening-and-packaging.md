# TISSUE-008：取消、恢复、集成验收与打包

- 状态：待办
- 类型：工程
- 优先级：P1
- 依赖：TISSUE-002 至 TISSUE-007
- 关联：[PRD](../../PRD.md)、[ADR-0001](../adr/0001-local-desktop-search-and-excel-automation.md)

## 目标

完成跨组件的稳定性治理、端到端验收和 Windows 可安装交付，使应用脱离开发环境后仍可可靠运行。

## 范围

- 统一文件准备、搜索和导出的任务状态与协作式取消机制。
- 统一 COM、SQLite、临时文件和后台线程的资源释放顺序。
- 处理应用关闭时仍有任务运行的情况。
- 建立启动时遗留临时索引和未完成临时导出文件的清理策略。
- 建立用户可理解的错误分类和恢复提示。
- 完成性能基准、长时间运行和重复操作测试。
- 选择并配置 Windows 打包方式，生成不依赖 Python 开发环境的安装产物。
- 编写安装、卸载、运行前提和已知限制说明。

## 关键异常场景

- Excel 未安装、COM 注册损坏或 Excel 启动失败。
- 文件损坏、受密码保护、被占用或处理中发生变化。
- 用户在准备、搜索或导出期间取消或关闭应用。
- 临时目录、保存目录无权限或磁盘空间不足。
- 单个文件失败但其他文件可以继续。
- Excel 弹出兼容性、链接、只读或格式警告。
- 上次异常退出留下临时文件或应用创建的 Excel 实例。

## 非范围

- 不实现自动联网更新、遥测上传或崩溃内容上传。
- 不通过结束所有 Excel 进程解决资源泄露。
- 不新增 PRD 之外的搜索功能。

## 验收标准

1. PRD 第 11 节全部验收标准通过。
2. 准备、搜索和导出在取消后均回到一致、可继续操作的状态。
3. 连续执行至少 20 次完整流程后，无应用创建的 Excel 进程或临时数据库残留。
4. 单文件失败不会清除其他成功文件的索引或结果。
5. 应用关闭时能够等待或取消后台任务，不发生崩溃和源文件修改。
6. 目标 Windows 电脑无需安装 Python 即可安装并运行应用。
7. 安装包中的依赖版本可追溯，发布说明列出 Windows、Office 和文件格式支持范围。
8. 日志不包含单元格内容、关键词或搜索结果。

## 测试要求

- 完整用户旅程端到端测试。
- 失败注入、取消、关闭和恢复测试。
- 多文件、10 万行及更大样本的性能与资源监测。
- 不同 Windows 缩放比例和目标 Office 版本烟雾测试。
- 安装、升级同版本、卸载和重新安装测试。

## 交付物

- 统一任务与资源生命周期实现。
- 端到端测试报告和性能基准报告。
- Windows 安装产物。
- 安装说明、发布说明和已知限制。
