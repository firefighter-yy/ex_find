# TISSUE-003：会话级 SQLite 索引与文件准备

- 状态：完成
- 类型：功能
- 优先级：P0
- 依赖：TISSUE-001、TISSUE-002 的数据契约
- 关联：[PRD](../../PRD.md)、[ADR-0001](../adr/0001-local-desktop-search-and-excel-automation.md)

## 目标

将 Excel 分块读取结果写入临时 SQLite 数据库，使多文件准备过程可控、内存占用有界，并为重复搜索提供稳定的数据来源。

## 范围

- 设计文件、工作表、物理行、单元格及准备状态的数据模型。
- 为精确匹配、行级聚合和结果排序建立必要索引。
- 使用事务按块写入，并在文件完成后原子标记为可搜索。
- 记录源文件路径、大小和修改时间，用于结果过期检测。
- 支持删除单个文件索引、清空会话和异常回滚。
- 在应用临时目录创建数据库，正常退出时删除。
- 提供准备进度、取消状态及失败原因，不保存单元格内容到日志。

## 数据约束

- 空单元格不入库。
- 索引只保存搜索和预览所需数据，不保存样式、图片或工作簿二进制对象。
- 所有查询和写入使用参数绑定。
- 未完成或失败文件的数据不能出现在搜索结果中。
- 多个同名文件、同名工作表必须通过内部标识区分。

## 非范围

- 首版不跨应用启动复用索引。
- 首版不承诺使用 FTS 或专用子串索引。
- 不负责 Excel 文件读取和最终导出。

## 验收标准

1. 可同时索引多个文件和多个工作表，且来源定位无冲突。
2. 持续分块写入时，应用内存不会随全部单元格内容线性无限增长。
3. 准备失败或取消后，该文件不会产生部分可搜索结果。
4. 删除一个已选文件后，其索引数据全部移除，其他文件不受影响。
5. 源文件大小或修改时间变化时，可以将相应索引标记为过期。
6. 应用正常退出后，会话数据库被删除。
7. 应用异常退出遗留的数据库可在下次启动时识别并清理，且不会被当作有效会话使用。

## 测试要求

- 数据模型迁移或初始化测试。
- 块事务成功、失败和取消回滚测试。
- 同名文件、同名工作表和重复导入测试。
- 大批量插入性能和临时磁盘空间不足测试。
- SQL 参数绑定和日志脱敏检查。

## 交付物

- SQLite schema 和索引仓库接口。
- 文件准备服务及状态模型。
- 临时数据库生命周期管理和测试。

## 完成验证

- `ex_transform.session_index.SessionIndex` 建立文件、工作表、物理行和单元格模型，并为文件状态、稳定排序、精确值及行级读取建立索引。
- `FilePreparationService` 直接消费 Excel 读取器的分块回调；每个文件在独立事务中准备，成功后原子标记为 `ready`，失败或取消时回滚全部工作表、行和单元格记录。
- 文件记录保存绝对路径、大小和纳秒修改时间；`mark_stale` 可在源文件变化或消失后将索引移出可搜索集合。
- 支持重复导入替换、单文件级联删除、会话清空、后台准备、进度转发与协作式取消。
- 自动创建 `excel-search-*` 临时会话目录，正常关闭时删除；启动新会话前清理无活动进程标记的遗留目录。
- 单元测试覆盖 schema、同名文件/工作表隔离、事务回滚、重复导入、过期检测、失败/取消和临时目录生命周期。
