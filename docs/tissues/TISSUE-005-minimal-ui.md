# TISSUE-005：极简搜索与结果预览界面

- 状态：待办
- 类型：功能
- 优先级：P0
- 依赖：TISSUE-001、TISSUE-003、TISSUE-004
- 关联：[PRD](../../PRD.md)

## 目标

提供单窗口极简工作流，让用户完成文件准备、关键词输入、规则选择、搜索和结果预览，不暴露底层 Excel 或数据库概念。

## 核心界面

- 文件选择入口和已选文件简表。
- 文件准备状态、进度、失败原因及移除操作。
- 单个极简关键词输入框，按 Enter 将内容添加为关键词标签。
- 删除单个关键词和清空全部关键词。
- AND / OR 分段选择控件。
- 精确匹配 / 包含匹配分段选择控件。
- 搜索按钮、取消按钮和结果数量。
- 可分页或虚拟滚动的结果表格。
- 导出按钮；在 TISSUE-007 完成前可保持禁用或使用明确的未实现状态。

## 结果预览规则

- 固定显示来源文件、工作表和原始行号。
- 展示来源工作表有效列范围内的整行值。
- 显示或标记命中关键词及命中列。
- 超宽工作表支持横向滚动，动态内容不得使工具栏位移。
- 多个独立表格仍按物理行展示，不推断表头。
- 不同来源行的列结构不同时，不伪造统一业务表头；使用来源列标识或分组展示。

## 状态规则

- 没有已准备文件或没有有效关键词时，搜索不可用。
- 搜索运行时可取消，重复提交不可用。
- 没有结果时，显示空状态且导出不可用。
- 源文件变更导致索引过期时，要求重新准备后才能搜索或导出。
- 错误信息应说明文件和可执行的恢复动作，不显示原始 COM 异常堆栈。

## 非范围

- 不实现多窗口、账户、主题市场或复杂设置页。
- 不实现可编辑结果表格。
- 不在界面中提供高级 SQL、正则表达式或列条件构建器。

## 验收标准

1. 用户能从空状态完成选文件、等待准备、输入关键词并获得结果。
2. AND / OR 和精确 / 包含选项可见且当前状态明确。
3. 输入多个关键词、删除关键词和清空关键词操作不需要打开额外对话框。
4. 搜索和文件准备期间主窗口保持响应并可取消。
5. 结果可追溯到来源文件、工作表和原始行号。
6. 超宽、长文本和大量结果不会导致控件重叠或主界面明显卡顿。
7. 所有禁用和错误状态符合本任务的状态规则。

## 测试要求

- UI 状态机测试和关键交互测试。
- 空文件、准备失败、无关键词、无结果和索引过期状态。
- 多文件、多工作表、超宽行、长文本和大量结果测试。
- 常用桌面分辨率及 Windows 缩放比例下的截图检查。

## 交付物

- 主窗口和必要的 UI 组件。
- 视图模型或控制器层。
- 关键流程自动化测试和截图。
