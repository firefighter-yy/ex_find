# ADR-0002：MVP 默认采用抽取模式，原貌模式作为显式选项

- 状态：已接受（MVP 技术验证结论）
- 日期：2026-08-26
- 决策者：项目所有者
- 关联：[TISSUE-006](../tissues/TISSUE-006-export-fidelity-spike.md)

## 背景

Excel 的工作表复制可以保留大量工作表级对象，但“复制完整工作表再隐藏未命中行”会把未命中的单元格和对象一并带入结果文件。反之，逐行复制到新工作簿适合搜索结果交付，却不能保证跨行结构和所有工作簿对象的语义不变。

本次原型由 `ex_transform.export_fidelity.ExportFidelitySpike` 提供两条可重复路径：`extract` 将选中的物理行复制到新工作簿；`appearance` 复制完整来源工作表并隐藏未命中行。两条路径均通过独立 Excel COM 实例打开源文件，源工作簿只读，输出先写同目录临时文件，成功关闭后才替换目标文件。

## 样本矩阵结论

| 对象/场景 | 抽取模式 | 原貌模式 | MVP 结论 |
| --- | --- | --- | --- |
| 字体、填充、边框、对齐、数字格式 | 选中行可保留 | 可保留 | 抽取满足常规结果交付 |
| 行高、列宽、隐藏行列、冻结窗格、筛选 | 行高/列宽需显式复制，工作表设置不保证 | 通常保留 | 原貌可选 |
| 横向合并 | 命中行内可保留，跨行范围不保证 | 可保留 | 抽取降级 |
| 纵向合并 | 语义可能断裂 | 可保留 | 原貌优先 |
| 条件格式、数据验证、批注 | 仅命中区域可部分保留 | 通常保留 | 抽取降级 |
| 公式、跨行/跨表引用 | 公式文本可复制，但引用语义可能改变 | 可保留 | 原貌优先 |
| 外部链接、图片、图表、形状、数据透视表 | 无法保证 | 通常保留，但仍受 Excel 版本/源对象限制 | 不作绝对承诺 |
| `.xlsm` 宏 | 不执行；抽取不复制宏项目 | 可随工作簿保留，仍不执行 | 原貌优先且警告 |
| 同表多个独立表格 | 只带命中物理行 | 未命中表格仍存在 | 抽取默认 |
| 多文件同名工作表 | 通过安全唯一名称区分 | 通过安全唯一名称区分 | 两者支持 |

## 决策

1. MVP 默认使用**抽取模式**，因为它不会把未命中的敏感数据静默带入导出结果。
2. 后续正式导出可提供**原貌模式**，必须由用户明确选择，并在 UI 中显示“结果包含未命中数据”的隐私警告。
3. 对跨行合并、跨行公式、图表/透视表、外部链接和宏等对象，抽取模式只能声明“降级保留”或“无法保证”；不得宣称“全部保留”。
4. 两种模式都必须在独立 Excel 实例中执行，源文件不得调用 `Save`/`SaveAs`，失败或取消时删除临时输出并关闭应用创建的工作簿和进程。

## 后续约束

正式实现（TISSUE-007）必须在导出前验证源文件大小和修改时间未变化，并保留来源文件、工作表和原始行号的追溯信息。该任务不在本原型中接入 UI。
